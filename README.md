# NEXORA Chain

NEXORA is an independent EVM-compatible blockchain built with Cosmos EVM. Its
native coin is NEX (`anex` base denomination, 18 decimal places).

The repository contains the Cosmos EVM local-chain setup and a Hardhat contract
workspace. Follow the [NEXORA local-devnet guide](nexora-config/README.md) to
build, initialize, and start the chain, then use [NEXORA Core](nexora-core) to
build and deploy Solidity contracts.
